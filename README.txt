WoWVita - game data converter for the PS Vita (Windows)

convert-test.cmd   Elwynn Forest + Northshire, interface and sound (tens of minutes) - start with this
convert-all.cmd    the whole game (hours, several GB)
w3dgui.exe         the same with a window (tick what to convert, press Start)
w3dconv.exe        the command-line converter
w3dpreview.exe     PNG previews of converted packs

How to use:
1. Drag your WoW 1.12.1 "Data" folder onto convert-test.cmd (or double-click it and type the path).
2. The result is in the "wowvita" folder next to this file.
3. On the Vita, copy everything from "wowvita" except log_*.txt to ux0:data/wowvita/ (VitaShell, USB or FTP).
4. Start WoWVita.

The converted files contain data from the game - do not share them.
